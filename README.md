# Christopher Edwards Portfolio

## Project Overview

This portfolio website showcases my Information Technology education, projects, skills, career goals, and contact information. The website was designed with accessibility, responsive design, and consistent visual styling in mind.

## Accessibility Fixes

- Added descriptive page titles to all three pages.
- Used semantic HTML elements including `header`, `nav`, `main`, `section`, and `footer`.
- Added clear navigation links to all three pages.
- Added visible keyboard focus indicators to navigation links, form controls, and buttons.
- Added proper `<label>` elements to all contact form fields.
- Used `<fieldset>` and `<legend>` to group related contact information.
- Added required validation to the contact form fields.
- Added accessible error states using `aria-invalid` and `aria-describedby`.
- Added visible error messages to help users understand how to correct invalid information.
- Updated text and background colors to improve WCAG AA contrast.
- Changed hover states so text remains readable against the background.
- Added reduced-motion support for users who prefer less animation.
- Used consistent spacing and alignment throughout all three pages.
- Tested all three pages with WAVE and corrected accessibility errors identified during testing.

## Visual Design

### Color Palette

The same color palette is used throughout all three pages to create a consistent visual design.

| Color | Hex Code | Purpose |
|---|---|---|
| Light Blue | `#00A8CC` | Navigation and primary accent |
| Navy Blue | `#0B3D91` | Header, borders, buttons, and headings |
| Dark Blue | `#003FAC` | Footer |
| Gold | `#D4A017` | Accent and highlights |
| Light Background | `#FBF4F4` | Main page background |
| Dark Text | `#1F2937` | Body text |
| White | `#FFFFFF` | Section backgrounds and header/footer text |

## Gestalt Principles

### Proximity

I used proximity to group related information together by placing content into separate sections with consistent spacing.

### Similarity

I used similarity by using the same colors, fonts, borders, spacing, navigation design, and section styling across all three pages.

## Responsive Design

The website uses CSS Grid, Flexbox, and media queries to create a responsive layout.

- Mobile: 320px and above
- Tablet: 768px and above
- Desktop: 1200px and above

The navigation also wraps when necessary so that the links remain accessible on smaller screens.

## Accessible Contact Form

The About/Contact page includes an accessible contact form with:

- Proper `<label>` elements
- `<fieldset>` and `<legend>`
- Required form fields
- Keyboard-accessible controls
- Visible focus indicators
- Accessible error messages
- `aria-invalid` for invalid fields
- `aria-describedby` connecting fields to their error messages
