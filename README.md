# Christopher Edwards Portfolio

## Accessibility Fixes

- Added descriptive page titles to all three pages.
- Used semantic HTML elements such as header, nav, main, section, and footer.
- Added labels, a fieldset, and a legend to the contact form.
- Added keyboard focus styles and required fields to improve accessibility.
- Verified text and background color combinations meet WCAG AA contrast requirements.

## Gestalt Principles

- **Proximity:** Related content is grouped together in separate cards and sections.
- **Similarity:** All pages use the same colors, fonts, borders, and spacing to create a consistent design.

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Google Fonts
